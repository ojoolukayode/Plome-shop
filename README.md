# Plome — Luxury Haute Parfumerie

A high-performance, accessible, and responsive luxury perfume shop built with React, Vite, and Tailwind CSS.

## 🚀 Features
- **Low-Bandwidth Optimized**: CSS-generated product graphics (zero image payloads)
- **WCAG 2.1 AA Accessible**: Skip links, keyboard navigation, ARIA attributes
- **Smooth Animations**: Battery-friendly scroll reveals via IntersectionObserver
- **Fully Responsive**: Mobile-first design with dedicated mobile navigation

## 🌐 Live Demo
Deployed on Vercel.

## 🛠️ Tech Stack
- React 18
- Vite 5
- Tailwind CSS 3
